# Security Policy

## Secure development

Do not commit signing keys, API keys, device backups, debug logs, emulator snapshots, or personal data. Review manifest export status, intent handling, camera permissions, backup rules, and external content before distributing an APK.

Use current AndroidX and dependency versions appropriate for the project, validate external intents, and avoid logging sensitive input.

## Reporting

Report suspected vulnerabilities privately to Brajesh Kumar (`@brajesh31`) rather than opening a public issue. Include the affected activity/resource, impact, reproduction steps, and a redacted proof of concept.
