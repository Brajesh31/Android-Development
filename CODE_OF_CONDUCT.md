# 🌱 Community Code of Conduct

Android Development is a learning repository. Contributors should be able to ask questions, discuss Android behaviour, challenge implementation choices, and improve examples without personal hostility.

## Our Commitment

We aim for respectful, constructive, and inclusive collaboration regardless of technical experience, background, or preferred development environment.

## Expected Behaviour

- Be respectful and patient.
- Critique code and design decisions, not people.
- Explain technical feedback with evidence.
- Welcome genuine beginner questions.
- Respect privacy and security boundaries.
- Credit external libraries and assets accurately.
- Be honest about tests and implementation limitations.
- Accept corrections professionally.

## Unacceptable Behaviour

- Harassment, discrimination, threats, or intimidation.
- Personal attacks or deliberate humiliation.
- Publishing private information without permission.
- Retaliation against good-faith reporters.
- Deliberate disruption or spam.
- Sharing signing credentials, tokens, or private data.
- Misrepresenting untested code as production-ready.

## Technical Disagreement

Different Android approaches can be appropriate for different SDK versions and use cases. Discuss lifecycle, architecture, permissions, and dependencies through reproducible examples and clear trade-offs.

## Reporting a Concern

Contact the repository owner privately through GitHub. For security vulnerabilities, use SECURITY.md rather than a public issue. Avoid attaching private user data or credentials.

## Enforcement

Maintainers may remove inappropriate content, issue warnings, restrict participation, or take other proportionate action. Retaliation against a person reporting a concern in good faith is prohibited.
