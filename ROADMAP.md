# Roadmap

## Maintainability

- Consolidate duplicate learning screens and establish a single navigation entry point.
- Replace hard-coded UI text with complete string resources.
- Add unit and instrumented coverage for adapters, calculators, intents, and prayer flows.
- Upgrade dependencies deliberately with Gradle verification.

## User experience

- Improve accessibility labels, keyboard/focus behavior, dark theme consistency, and responsive layouts.
- Add explicit permission education and graceful fallback when camera or device features are unavailable.

## Release readiness

- Define a release signing process outside Git.
- Review exported activities, backup behavior, dependency licenses, and privacy disclosures before publishing.
