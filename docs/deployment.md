# Deployment

Before producing a release APK or App Bundle:

1. Run unit, instrumented, and release builds.
2. Review exported components, permissions, backup rules, and deep links.
3. Audit dependency licenses and known vulnerabilities.
4. Configure signing through a local or CI secret store; never commit keystores.
5. Test camera and other device features on representative hardware.

The current project is a learning sandbox and should not be published without consolidating launcher activities and reviewing privacy behavior.
