## 🧭 Recommended reading

**New learner:** start with the root README, Features, Installation, and Architecture.

**Changing an Activity:** read Activity Lifecycle, Navigation, Testing, and Security and Permissions.

**Changing UI:** read Resources and Layouts and Accessibility.

**Preparing a build:** read Build and Release and Troubleshooting.

## ⚠️ Documentation accuracy

This repository is a learning application with multiple sample screens. The documentation describes the current tree and known project-level configuration. It does not claim a production-ready single navigation graph, backend, database, or complete test coverage.
