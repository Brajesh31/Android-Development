# Contributing

Contributions should keep this repository useful as an Android learning project.

- Use Kotlin and existing AndroidX/Material patterns.
- Keep activities, layouts, adapters, and models focused and explain non-obvious lifecycle behavior.
- Put user-visible text in `strings.xml`; provide accessible content descriptions for meaningful images.
- Request and handle runtime permissions explicitly.
- Do not commit keystores, signing credentials, local SDK paths, generated APKs, or personal data.
- Run `gradlew.bat test` and, when available, `gradlew.bat connectedAndroidTest`.

Pull requests should describe the learning objective, affected screens, device/API validation, and any permission or dependency changes.
